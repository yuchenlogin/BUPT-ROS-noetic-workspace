- **案例演示**
    - 在机器人中有人脸追踪的案例实现。
        ```shell
        cd robot_ros_application/catkin_ws/
        source devel/setup.bash
        rosrun ros_higher_vocational_training_platform face_tracking.py
        ```
        ![image1](image/%E4%BA%BA%E8%84%B8%E8%BF%BD%E8%B8%AA-%E4%BB%A3%E7%A0%81%E8%BF%90%E8%A1%8C.png)  
        在摄像头前移动，Roban头部舵机会跟随你的人脸转动，当然头部不是360°的自由度，一般为正面的+90~-90°。  
        结束程序可以使用“ctrl + c”。  
        你也可以用vnc-viwer软件或连接机器人的屏幕执行这个命令：  
        ```shell
        cd robot_ros_application/catkin_ws/
        source devel/setup.bash
        rosrun ros_higher_vocational_training_platform face_tracking.py debug
        ```
        这会在系统中显示机器人摄像头的实时图像，识别出的人脸结果会被一个红色矩形框起。  
        ![image2](image/%E4%BA%BA%E8%84%B8%E8%BF%BD%E8%B8%AA-%E4%BB%A3%E7%A0%81%E8%BF%90%E8%A1%8C2.png)
- **部分代码解读**
    - 主体结构  
        ![image3](image/%E4%BA%BA%E8%84%B8%E8%BF%BD%E8%B8%AA-code1.png)  
        主程序中创建了三个线程，分别是 detecFace 、thread_face_center、 thread_set_servos，分别对应人脸检测、计算人脸距离图像中心的距离和舵机控制的功能。  
    - 人脸检测  
        ![image4](image/%E4%BA%BA%E8%84%B8%E8%BF%BD%E8%B8%AA-code3.png)  
        ![image5](image/%E4%BA%BA%E8%84%B8%E8%BF%BD%E8%B8%AA-code2.png)  
        调用 opencv 的 Face++ 人脸识别库，识别人脸在图像中的坐标。    
    - 计算人脸距离图像中心距离  
        ![image6](image/%E4%BA%BA%E8%84%B8%E8%BF%BD%E8%B8%AA-code4.png)  
        Face.error_pan 和 Face.error_tlt 代表 人脸在 x 和 y 方向上的距离。

        ![image7](image/%E4%BA%BA%E8%84%B8%E8%BF%BD%E8%B8%AA-code5.png)
