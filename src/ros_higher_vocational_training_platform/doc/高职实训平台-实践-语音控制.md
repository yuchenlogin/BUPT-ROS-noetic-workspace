    - 自定义动作设计

        - Roban 软件动作设计步骤：

            - 新建工程文件，应该以每一个动作新建独立的工程文件，下载到机器人内会在指定目录生成以工程文件命名的 python 文件

                - ![新建工程文件](../../../../doc/AIUI%E9%85%8D%E7%BD%AEFAQ_IMG/%E6%96%B0%E5%BB%BA%E5%B7%A5%E7%A8%8B.png)

            - 选择插入帧的位置，右键添加关键帧，选择全身即可

                - ![插入关键帧](../../../../doc/AIUI%E9%85%8D%E7%BD%AEFAQ_IMG/%E6%8F%92%E5%85%A5%E5%85%B3%E9%94%AE%E5%B8%A7.png)

            - 点击软件界面右侧机器人模型，选择需要控制的机器人关节部位，选择需要控制的舵机，拖动时间轴或输入码盘数值，机器人相应位置舵机会发生转动

            - 再点击确认按钮，当前这一帧的动作便会插入到动作帧位置。需要注意的是，动作帧时间轴单位 1f = 10ms

                - ![插入关键帧](../../../../doc/AIUI%E9%85%8D%E7%BD%AEFAQ_IMG/%E8%AE%BE%E7%BD%AE%E8%88%B5%E6%9C%BA%E7%A0%81%E7%9B%98%E7%9A%84%E6%95%B0%E5%80%BC.png)

            - 按同样的步骤，在开始帧和结束帧之间插入多个关键帧

            - 点击 "生成模块"，会将动作帧内容以模块化形式进行封装

                - ![生成自定义动作](../../../../doc/AIUI%E9%85%8D%E7%BD%AEFAQ_IMG/%E7%94%9F%E6%88%90%E8%87%AA%E5%AE%9A%E4%B9%89%E5%8A%A8%E4%BD%9C.png)

            - 将生成的动作模块，放在开始程序内，点击 "下载"

                - ![下载动作](../../../../doc/AIUI%E9%85%8D%E7%BD%AEFAQ_IMG/%E4%B8%8B%E8%BD%BD%E5%8A%A8%E4%BD%9C.png)

            - 文件将被下载到 `/home/lemon/robot_ros_application/catkin_ws/src/ros_actions_node/scripts/` 下，以工程文件命名的 python 文件

        - 将下载的文件路径加入配置文件中，如设计了摆手的动作，加入配置文件后应如下图：

            ![image6](image/%E8%AF%AD%E9%9F%B3%E6%8E%A7%E5%88%B6-code7.png)
