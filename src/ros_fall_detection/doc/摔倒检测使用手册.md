## 摔倒检测

### 配置文件

- /ros_fall_detection/configs/config.json

    - 配置摔倒检测模型相关参数

        ```json
        {
            "label": [
                "fall"
            ],
            "model_parameters": {
                "mean": [0.485, 0.456, 0.406],
                "std": [0.229, 0.224, 0.225],
                "input_resize": {
                    "width": 608,
                    "height": 608
                }
            }
        }

        ```

- /ros_fall_detection/configs/fall_detection_config.json

    - 配置识别到摔倒后的语音播报

        ```json
        {
            "check": {
                "text": "摔倒检测已开启,让我看看有没有人摔倒。",
                "vcn": "qige",
                "speed": 50,
                "pitch": 5,
                "volume": 20
            },
            "fall": {
                "text": "检测到有人摔倒,这里需要帮助",
                "vcn": "qige",
                "speed": 50,
                "pitch": 5,
                "volume": 20
            }
        }

        ```

### 案例运行

- 终端启动

    ```shell
    $ source ~/robot_ros_application/catkin_ws/devel/setup.bash
    $ roslaunch ros_fall_detection fall_detection.launch
    ```

### 案例调试

- 显示图像
  在fall_node.py的文件第62 63行，如果想显示摄像头的图像则将注释取消即可。  
    ```shell
    cv2.imshow("Camera Image", cv_image)
    cv2.waitKey(1)  # 等待按键输入（单位：毫秒） 
    ```

- 更换置信度
  如果觉得摔倒检测的置信度太低或者太高，可以将fall_node.py文件中第14行中的FALL_CONFIDENCE_THRESHOLD = 0.8进行调整即可。
